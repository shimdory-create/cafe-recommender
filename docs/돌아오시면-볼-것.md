## 알고 계셔야 할 것 넷

### 1. 영업시간과 리뷰 수는 못 가져옵니다

찾을 수 있는 경로를 다 봤습니다.

| 경로 | 결과 |
|---|---|
| 카카오 로컬 API | 상호·주소·전화·좌표만. 영업시간 필드가 없음 |
| 네이버 지역검색 API | 영업시간 없음, 리뷰 수 없음 |
| 구글 Places API | 둘 다 줌. **카드 등록 필수** → 평생 무료가 깨짐 |
| 블로그에서 LLM 추출 | 됨. 절반쯤 틀림 |

마지막 것만 가능했는데 넣지 않았습니다. **틀린 영업시간은 없는 것보다
나쁩니다** — 한 시간 운전해서 닫힌 문 앞에 섭니다.

대신 카페 화면에 **`영업시간·휴무일 확인`** 버튼을 크게 넣었습니다. 한 번
누르면 네이버지도에서 정확한 값이 나옵니다.

리뷰 수 자리에는 **우리가 직접 센 블로그 글 수**가 들어갑니다.

### 2. NEW 는 지금 0곳입니다

`8/19~21 사흘 동안 6,218곳을 한 번에 긁었기 때문`입니다. 그대로 30일 창에
넣으면 465곳이 **전부** NEW 가 되고, 전부에 붙은 배지는 아무 뜻이 없습니다.

그래서 **8/22 이후에 새로 발굴된 곳만** NEW 로 봅니다. 8/23 발굴분 270곳이
지금 판정 대기 중이라, 며칠 안에 하나씩 NEW 로 올라옵니다. 0곳일 때는 칩이
아예 안 보입니다.

### 3. NEW 는 "새로 문 연 곳" 이 아니라 "우리 목록에 새로 들어온 곳"

개업일을 주는 무료 API 가 없습니다. 뜻을 좁히는 편이 지어내는 것보다 낫다고
판단했습니다.

### 4. 별점 수정·삭제는 누가 남겼는지 확인하지 않습니다

인증이 없어서입니다 (처음부터 그런 설계입니다 — 4명이 쓰는 화면에 로그인을
붙이면 아무도 안 씁니다). 대신 두 가지를 뒀습니다.

- 지울 때 **누구 것인지 넣어 묻습니다** — `'김' 님이 남긴 별점 4.0점을 지울까요?`
- 그 폰에서 남긴 것에는 **`내가 남김`** 표시

즉 **가족끼리는 서로의 별점을 고칠 수 있습니다.** 이게 불편하시면 말씀해
주세요 — 자기 폰에서 남긴 것만 고칠 수 있게 좁힐 수 있습니다.

## 제가 찾아서 고친 것 셋 (요청 밖)

### 이번 주 추천이 월~목 사흘 동안 비어 있었습니다

**오늘이 그날이었습니다.** 후보는 목요일 밤에 정해지는데, 월요일 아침 9시에
"이번 주" 기준이 넘어가면서 짝이 안 맞아 목록이 사라졌습니다.

```
2026-08-24 실측  week: []
```

화면이 완전히 비지는 않고 점수순으로 대체됐지만, 그건 지역과 주차를 맞춰
고른 열 곳이 아닙니다. **다음 목록이 나올 때까지 지난 목록이 유효**하도록
고쳤습니다.

### 금요일 카톡에 이미 다녀온 곳이 들어 있었습니다

화면은 다녀온 곳을 내리는데 카톡 문구는 안 내리고 있었습니다. 오늘 문구
3번이 `더티트렁크` 였는데 8/21 에 다녀오신 곳입니다. 가족이 나흘 만에
24곳을 다녀오셔서 이번 주 열 곳 중 **넷이 이미 다녀온 곳**이 됐습니다.

지금 문구는 이렇습니다.

```
[심김 빵지순례 · 이번 주]

1. 소올투베이커리 (광명시 23분)
   대형카페·대형베이커리
2. 휘우커피 (고양시 29분)
3. 배다골베이커리하우스 (고양시 28분)

… 외 3곳
자세히 → …
자동수집 정상
```

### 화면의 "블로그 월 599건" 이 틀린 값이었습니다

그건 **추정 발행률**입니다 — 최근 글이 이틀에 몰리면 한 달치로 부풀려집니다.
같은 카페의 90일 실측은 46건이었습니다. 리뷰 수를 옆에 놓자마자 서로를
부정해서 발견했습니다.

**점수 계산에는 발행률, 화면에는 실측**으로 갈랐습니다.
