## 1. 방향 묶음 (요청 작업)

행정구역으로 모아 보고 싶다는 요청이었는데, 실측 분포가 시군구 칩을 막았습니다.

```
표시 대상 209곳이 43개 시군구에 흩어져 있고, 17개는 1~2곳뿐
```

칩 43개는 화면 세 줄을 먹고 절반은 카드 한 장을 위한 칩이 됩니다. 그래서 **두 층**
으로 만들었습니다.

| 층 | 내용 |
|---|---|
| 1층 | 방향 6칩 + 개수 — 가까운 곳 15 · 서울 26 · 서쪽 21 · 북쪽 37 · 동쪽 58 · 남쪽 52 |
| 2층 | 방향을 고르면 **그 안에서 시군구별로** 묶어 가까운 지역부터 |

원래 요청은 2층에서 충족되고, 첫 화면은 6칩으로 단순합니다. 동쪽을 누르면:

```
동쪽 — 양평군·남양주시·가평군·광주시 등 7개 지역 · 가까운 지역부터
  하남시   5곳 · 가장 가까운 곳 48분
  광주시   6곳 · 가장 가까운 곳 51분
  남양주시 16곳 · 가장 가까운 곳 51분
  ...
```

**부수 효과**: "가까운순" 정렬이 의미를 갖게 됐습니다. 지금까지는 광명 23분,
계양 25분, 김포 25분이 섞여 나왔는데 전혀 다른 방향입니다.

## 2. 검증 3회에서 찾아 고친 것

### 1차

| 문제 | 영향 |
|---|---|
| 같은 카페가 목록에 두 번 (`비루개`, `터프이너프 로스터스`) | 추천 10칸 중 두 칸을 같은 카페가 먹을 수 있었음 |
| 방향 설명이 배정과 어긋남 (동쪽에 이천·여주 누락) | 그 지역을 찾는 사람은 동쪽을 눌러볼 이유가 없음 |
| 카드 제목이 지역 헤더와 같은 단계 | 화면 구조가 평평해짐 |

### 2차 — 가장 큰 것

**`시군구`에 카페 주소가 아니라 "검색한 지역"이 들어가 있었습니다.**

```
active 299곳 중 20곳(6.7%) 불일치 / 전체 6,218곳 중 1,669곳(27%)
```

카카오에 `경기 양평군 대형카페`로 검색하면 경계 너머 남양주·광주 카페도 옵니다.
그걸 양평군으로 저장하고 있었습니다. 세 곳이 어긋났습니다 — 카드 표기, 지도 링크
(`양평군 라온숨`으로 검색), 그리고 방금 만든 지역 묶음.

**부수 소득: 2026년 인천 행정구역 개편을 발견했습니다.** 주소에 `서해구` 89곳,
`제물포구` 44곳, `영종구` 23곳, `검단구` 16곳이 있었습니다. 우리 지역 목록에 없던
이름이라 방향 묶음에서 조용히 '가까운 곳' 기본값으로 떨어질 상태였습니다.

또 하나: **추천 10곳에 같은 브랜드가 둘** 있었습니다 (배다골베이커리하우스 / 포레,
둘 다 고양시). 브랜드 이름 추측은 `베이커리카페 A`/`B` 같은 흔한 접두에서
오작동하므로 **같은 시군구 최대 2곳** 규칙으로 풀었습니다. 지점은 대개 같은 지역에
모이고, 43개 시군구가 있는데 한 곳에서 3곳을 뽑을 이유도 없습니다.

```
배다골베이커리 포레  →  타임투비 (용인시)
```

### 3차

남은 것은 옛 실패 기록 하나였습니다 — `kakao-local`에 Gemini 오류가 잘못 적혀
카톡 상태 줄이 "주의: 쿼터 오류"로 나오던 것. 실제 실행으로 정리했고 지금은
**이상 없음**입니다.

## 3. 새로 생긴 명령

```bash
npm run audit       # 데이터 정합성 점검 (키 없이 돈다)
npm run normalize   # 시군구를 주소 기준으로 정정 (멱등)
```

`watch`와 `audit`은 역할이 다릅니다. **watch는 운영 이상**(수집이 멈췄나)을 보고
매일 자동으로 돕니다. **audit은 데이터 정합성**(표시가 틀렸나)을 보고 사람이
돌립니다. 이번 검증에서 걸린 항목이 그대로 audit 규칙이 됐습니다 — 다음에는
손으로 찾지 않아도 됩니다.

## 5. 동료에게 공유할 때 알려줄 것

링크를 받은 사람은 **`다녀왔어요`를 누를 수 있습니다.** 누르면 그 카페가 우리
추천에서 6개월간 내려갑니다.

> **되돌릴 수 있습니다** — `다녀온 곳` 탭에서 "다녀온 곳에서 빼기"를 누르면 즉시
> 추천으로 돌아옵니다.

별점·후기도 남길 수 있고 카드에는 "가족 평점"으로 표시됩니다. 한두 명에게
참고용으로 주는 것이면 이 안내로 충분합니다.
