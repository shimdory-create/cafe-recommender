## 물어보신 것 세 가지

### 1. 포레스트아웃팅스 일산점·송도점은 왜 없었나

**프랜차이즈라서가 아니었습니다.** 상호를 블로그에서 찾는 방식이 지점명 붙은
카페에 불리했습니다.

우리는 글에 **상호명이 그대로** 있어야 "이 카페 얘기"로 셌습니다. 그런데
블로거는 `포레스트아웃팅스 일산본점`이라고 쓰지 않습니다 — `일산
포레스트아웃팅스`, `포레스트아웃팅스 본점`이라고 씁니다.

```
받은 글 50건 중 상호 전체가 그대로 있는 글    4건  ->  정밀도 8%  ->  탈락
```

용인점만 살아남은 건 우연입니다. `포레스트아웃팅스 용인점`이라는 정확한
표기를 쓴 글이 마침 많았습니다.

**기본 상호 + 지점 힌트**를 찾도록 고쳤습니다. `포레스트아웃팅스`와 `일산`이
둘 다 있으면 그 카페 글로 봅니다. 지점 힌트를 같이 요구해야 용인점 글이
송도점에 잡히지 않습니다.

| | 전 | 후 |
|---|---|---|
| 일산본점 | 정밀도 10% · 월 12건 | **84% · 월 73건** |
| 송도점 | 34% · 월 2.4건 | **80% · 월 64건** |
| 용인점 | 66% · 월 114건 | 94% · 월 163건 |

지점 카페 **470곳**이 새로 기준을 넘었습니다. 둘 다 지금 판정 대기이고
AI 무료 한도를 다 써서 멈췄습니다 — 오늘 자동 작업이 마무리하면 목록에
올라옵니다.

품질은 그대로입니다 (골든셋 오통과율 5%, 경계 50% 유지).

## 검증하다 찾아 고친 것 셋

### 표시 카페의 절반이 추정 거리였습니다

통과 카페가 683 → 1,035곳으로 늘었는데 실주행 측정은 주 1회입니다. 그 사이
**직선거리로 어림한 값**이 화면에 "차로 28분"으로 떠 있었습니다.

```
강화 +18.9분 · 검단 +16.2분   (실제로는 더 멀다)
여주 -33.7분 · 이천 -27.4분   (실제로는 더 가깝다)
```

카드 숫자만 틀리는 게 아닙니다. 지역 칩의 "가장 가까운 곳 N분", 가까운순
정렬, 추천 점수가 전부 이 값을 씁니다. **1,041곳 전부 실측**으로 채웠습니다.

### 이번 주 열 곳 중 넷이 이미 다녀온 곳이었습니다

목록은 목요일 밤에 굳고, 다녀온 곳은 6개월간 내려갑니다. 주중에 다녀오면
그만큼 빕니다 — 화면에는 여섯 곳만 남아 있었습니다.

이제 **후보를 20곳 뽑아 두고** 다녀온 곳을 뺀 뒤 열 곳을 채웁니다.

