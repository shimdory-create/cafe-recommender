## 1. 웹앱을 눈으로 보기 (2분)

```bash
npm run dev --prefix web
```

브라우저에서 `http://localhost:3000` — **모바일 화면으로 보세요.** 크롬 개발자도구
(F12) → 왼쪽 위 휴대폰 아이콘 → iPhone 15 정도로 맞추면 실제와 같습니다.

화면 3개를 봐주세요.

| 탭 | 볼 것 |
|---|---|
| 이번 주 | 추천 3곳. 카드 상단이 `규모 · 주차 · 메뉴` 로 3초 판단이 되는지 |
| 전체 | 태그 칩으로 좁혀지는지. `도심 포함` 을 켜면 89곳이 더 나오는지 |
| 정보 | 이 목록이 어떻게 만들어지는지 — 아내분께 설명할 때 쓸 화면 |

**여기서 고칠 것이 보이면 말씀해 주세요.** 배포 전에 고치는 게 낫습니다.

## 2. 접근 코드 정하기 (1분)

가족이 쓸 코드 하나만 정해주세요. 링크에 붙어서 오므로 **아무도 입력하지 않습니다** —
카톡 링크를 누르면 그냥 들어갑니다. 새 기기에서 직접 열 때만 입력창이 뜹니다.

- 예: `bupyeong2026`, `cafe-shim`
- 영문·숫자·하이픈이면 뭐든 됩니다

정해주시면 `.env` 와 Vercel 환경변수에 넣겠습니다.

---

## 3. Vercel 배포 (10분, 사용자님 계정 연결이 필요)

제가 대신 할 수 없는 부분입니다 (계정 로그인).

1. [vercel.com](https://vercel.com) 로그인 → **Add New → Project**
2. 이 저장소를 고릅니다 (GitHub 에 올려둔 곳)
3. 설정은 `vercel.json` 에 이미 다 넣어뒀으니 **그대로 두고**
4. **Environment Variables** 에 두 줄만 추가
   ```
   ACCESS_CODE  = (2번에서 정한 코드)
   SITE_URL     = https://(배포 후 받는 주소)
   ```
5. Deploy

> `data/` 가 커밋될 때마다 자동으로 다시 배포됩니다. 매일 도는 배치가 데이터를
> 커밋하므로 **손댈 일이 없습니다.**

배포가 끝나면 주소를 알려주세요. 카톡 문구에 넣겠습니다.
