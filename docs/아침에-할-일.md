## 남은 것 — 두 개뿐입니다

### ① Vercel 배포 (4분) ← 이것만 하면 링크가 나옵니다

[vercel.com/new](https://vercel.com/new)

1. **Import Git Repository** 에서 `cafe-recommender` 선택
   - 안 보이면 **Adjust GitHub App Permissions** → `cafe-recommender` 체크 → Save
2. **Root Directory** 를 `web` 으로 변경 ← 이게 중요합니다
3. **Environment Variables** 세 줄:

   | Name | Value |
   |---|---|
   | `ACCESS_CODE` | 가족 접근 코드 (예: `bupyeong2026`) |
   | `GITHUB_TOKEN` | `.env` 에 넣어둔 그 토큰 |
   | `GITHUB_REPO` | `shimdory-create/cafe-recommender` |

4. **Deploy** → 나온 주소를 저에게 알려주세요

> 환경변수를 안 넣어도 배포는 됩니다. 다만 접근 코드 없이 열리고(누구나 볼 수
> 있음) 별점 저장이 안 됩니다. 세 줄 넣는 편이 낫습니다.

### ② 주소 알려주기 → 금요일 정오 카톡

주소를 주시면 제가 카톡 문구를 완성하고 **금요일 정오 발송**을 걸겠습니다.
