# 계획 3 — 가족 웹앱

**Goal:** 아내분이 금요일 정오 카톡 링크를 눌러 **한 손 엄지로** 이번 주 추천을
순위대로 보고(10곳씩, 못 고르면 다음 10곳), 전체 리스트를 훑고, 카페 하나를 눌러
판단 근거까지 확인할 수 있게 한다.

**Spec:** `2026-08-19-cafe-recommender-design.md` 10절 · 10.1절 · 11절
**품질 기준선:** `2026-08-20-golden-set-results.md` (오통과율 5%, 경계 통과율 50%)

## Global Constraints

**아키텍처 경계 — 생성기와 소비자를 분리한다**

웹앱은 `data/*.json` 6,216곳을 직접 읽지 않는다. 파이프라인이 **표시용 페이로드**를
만들고 웹앱은 그것만 읽는다.

```
data/*.json (6,216곳, 4.7MB)
   -> npm run site   (src/site/payload.ts — 순수 함수 + zod)
   -> web/src/generated/site.json  (통과분만, 수십 KB)
   -> Next.js 정적 생성
```

이유가 세 가지다.

1. **점수·게이트 로직이 두 곳에 생기는 것을 막는다.** 스코어링은 이미
   `src/pipeline/score.ts` 에 있고 테스트가 있다. 웹에서 다시 계산하면 갈라진다
2. **번들 크기.** 4.7MB 를 모바일로 내려보내지 않는다
3. **오프라인.** 페이로드를 빌드 타임에 import 하면 fetch 가 없어 지하철에서도 뜬다

**모바일 우선 (스펙 10.1 — 협상 불가)**

- 375~430px 에서 설계하고 데스크톱은 `max-width: 480px` 센터 정렬
- **하단 탭바.** 상단 햄버거 금지
- 카드 1열 고정. 가로 스크롤 금지
- 터치 타겟 44px 이상, 폰트 15px 이상 (79/81년생에게 13px 은 작다)
- 이미지 지연 로딩 + 고정 aspect-ratio

**쓰기 엔드포인트 — 0개에서 2개로 바뀌었다 (v3.3~3.4).** "링크를 통해 접속한
모두가 별점과 후기를 남길 수 있게" 라는 요청이 명확했다. `/api/visited`,
`/api/reviews` 두 개를 두고, 저장은 GitHub Contents API (DB 없음).
공격 표면을 좁히는 방법은 세 가지다 — 저장 대상이 두 파일로 못박혀 있고,
**목록에 있는 카페 id 만** 받고, 값은 길이·범위를 검증한다.

**절대 금지**
- 지도 SDK 직접 구현 (네이버지도 링크로 넘긴다)
- 외부 CDN 의존 (오프라인에서 깨진다)
- `data/*.json` 을 웹에서 직접 import

## 계획에 없던 것 — 2회차 (2026-08-21)

사용자 요청 6건(이미지·방문 제외·취소·별점 표시·이름·설명)을 반영한 뒤,
"돌아가는 것처럼 보이지만 안 돌아가는" 것 세 가지를 잡았다.

- **자동 수집이 Actions 에서 전부 죽는 상태였다** — `tsx --env-file=.env` 는
  파일이 없으면 에러다. `.env` 는 커밋하지 않으므로 러너에는 없다.
  `--env-file-if-exists` 로 바꾸고 러너와 같은 조건으로 실제 실행해 확인했다.
  `weekly-drive` 에는 `GEMINI_API_KEY` 가 빠져 있었다 (LLM 을 쓰지 않아도
  환경변수 검증이 provider 키를 요구한다)
- **체크 직후가 "안 눌린 것" 처럼 보였다** — `/api/visited` GET 의 30초 캐시.
  방문 기록은 캐시하지 않는다. 후기는 자기 것이 즉시 보이므로 30초 유지
- **읽기 실패를 "기록 없음" 으로 보여줬다** — 토큰이 없거나 GitHub 읽기가
  실패해도 200 + 빈 배열이다. `ok` 플래그를 함께 내려보내고, 실패면 화면은
  마지막으로 알던 목록을 유지한다
- **쓰기 대상 검사** — 목록에 있는 카페 id 만 받는다. 취소 방향은 검사하지 않는다
- **iOS 홈 화면 아이콘** — icon.svg 와 같은 그림을 180px PNG 로 렌더 (빌드 단계
  추가 없이 정적 파일 한 장)
